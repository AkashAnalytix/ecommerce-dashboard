Amazon Sales Analysis Dashboard 📊

📌 Project Overview

This project presents an interactive sales analysis dashboard built using Microsoft Power BI. The dashboard provides insights into sales performance, product categories, outlet locations, outlet sizes, fat content, and customer ratings.

It helps users understand sales trends, compare outlet performance, and identify important business insights through interactive visualizations and filters.

🎯 Project Objectives

- Analyze total sales and average sales performance.
- Understand product distribution by fat content and item type.
- Compare sales across different outlet sizes and locations.
- Evaluate outlet performance based on establishment year.
- Analyze average customer ratings and the number of items sold.
- Build an interactive dashboard to support data-driven decision-making.

📊 Key Performance Indicators (KPIs)

- Total Sales: $1.20M
- Average Sales: 141.0
- Number of Items: 9K
- Average Rating: 3.92

📈 Dashboard Features

- KPI Cards: Display key sales metrics at a glance.
- Fat Content Analysis: Compare Low Fat and Regular products.
- Item Type Analysis: Visualize sales across product categories.
- Outlet Establishment Trends: Examine sales performance by establishment year.
- Outlet Size Analysis: Compare small, medium, and high-sized outlets.
- Outlet Location Analysis: Compare Tier 1, Tier 2, and Tier 3 locations.
- Outlet Type Analysis: Compare grocery stores and different supermarket types.
- Interactive Filters: Filter the dashboard by outlet location, outlet size, and item type.

🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query for data cleaning and transformation
- DAX for measures and calculations
- Data visualization and business intelligence
- BlinkIT Grocery Data

💡 Key Insights

- The dashboard reports approximately $1.20 million in total sales.
- Low Fat products account for around 64.6% of the displayed sales distribution.
- Tier 3 outlets contribute the highest sales among the three outlet location tiers.
- Supermarket Type 1 contributes the largest sales volume among the outlet types shown.
- The dashboard enables comparisons between product categories, outlet characteristics, and sales performance.
